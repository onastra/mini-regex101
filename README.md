# Mini Regex101

一个轻量级的在线正则表达式测试工具，灵感来源于 [regex101](https://regex101.com/)。

**在线体验**：[https://onastra.github.io/mini-regex101/](https://onastra.github.io/mini-regex101/)

## 功能特性

- **实时匹配**：输入正则或测试字符串时自动更新结果
- **Flags 支持**：`g` `m` `i` `y` `u` `s` `d` `v`
- **语法错误提示**：正则不合法时显示具体错误信息
- **匹配高亮**：用不同颜色标记匹配结果
- **分组可视化**：开启 `d` 标志后，不同捕获组使用不同背景色，并支持 tooltip 查看分组信息
- **零宽匹配提示**：对零宽断言等空匹配使用点状边框标记
- **滚动同步**：测试字符串与高亮结果区域同步滚动

## 使用方法

1. 在 **REGULAR EXPRESSION** 输入框中填写正则表达式
2. 勾选需要的 **FLAGS**
3. 在 **TEST STRING** 中输入要匹配的文本
4. 结果会实时显示在下方（或点击 RUN 按钮手动触发）

### 示例

正则：`(.(.)(.))(..)`  
测试字符串：任意包含至少 5 个字符的文本  
开启 `g` 和 `d` 标志后，可看到分组高亮效果。

## 技术说明

- 使用浏览器原生 `RegExp` 与 `exec` 进行匹配
- 依赖 `d`（hasIndices）标志获取分组起止位置，实现分组高亮
- 通过 GitHub Pages 部署

## 本地运行

直接用浏览器打开 `mini-regex101.html` 即可。
